# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

The Sabro Networks and Vshatkay Solutions engineering teams take security and telecom data privacy seriously.

If you discover a security vulnerability within this project:
1. Please do **not** open a public issue.
2. Email the maintainer directly at **security@vshatkaysolutions.com** or **info@sabronetworks.com**.
3. Include details of the vulnerability, steps to reproduce, and potential impact.
4. You will receive an initial response within 24 hours.
